Clase 5 · 18 min

Entrega con agentes: una carpeta por cliente, puertas de control humanas y secretos fuera

Los agentes hacen lo repetitivo: correr la radiografía, armar el informe, proponer títulos, escribir el borrador. Lo que da confianza al cliente es que nada sale al aire sin que un humano lo apruebe, y que su contraseña nunca está en tu repositorio. Una carpeta por cliente, siempre con la misma estructura.

Empezar la clase

En esta clase vas a

  1. 1La estructura de carpetas que se repite en cada cliente
  2. 2Dónde trabaja el agente y dónde solo decide el humano
  3. 3Por qué la puerta de control nunca se salta, ni con prisa
  4. 4Secretos fuera del repositorio y modelo por suscripción

Objetivo: armar la carpeta de un cliente con estructura fija, puertas de control humanas y secretos fuera del repositorio, para entregar con agentes sin perder control.

El agente acelera el trabajo; las puertas de control cuidan la confianza del cliente.

02 · Cómo montar la entrega

Haz clic en cada etapa.

1. Carpeta

Crea la carpeta con la estructura fija y un archivo de instrucciones para el agente (AGENTS.md o CLAUDE.md) con las reglas del cliente: tono, qué no publicar, quién aprueba.

Versión en git: cada cambio tiene fecha, autor y se puede deshacer.

2. Secreto fuera

Las claves y credenciales quedan en variables de entorno, nunca en el repositorio ni en el prompt.

El acceso a los paneles del cliente es de solo lectura, autorizado por escrito (clase 7).

3. Puertas de control

Si el cliente no tiene tiempo de revisar, la cadencia baja. La puerta de control no se salta.

Ayuda: el agente entrega el resumen de lo que cambió y las 3 cosas para que el cliente confirme.

En INEMAUn script de enlaces tomó el nombre equivocado de un curso en una subcarpeta. Se detectó en el piloto, antes del push. Para eso sirve correr en pequeño y revisar antes.

4. Revisar al agente

Todo número que produce el agente pasa por una cuenta de verificación: la parte no puede ser mayor que el todo.

En INEMA, un export sumó las impresiones de marca por consulta y página y dio más que el total de la semana. La corrección fue sumar solo por consulta.

03 · Plantillas de la carpeta

Copia y cambia lo que está entre < >.

Terminal · crear la carpeta del cliente
mkdir -p <cliente>/{docs,briefings,reports,scripts,data/gsc}
cd <cliente> && git init -b main
printf '.env\n*.key\ncredenciais/\n' > .gitignore
touch .env AGENTS.md data/urls-chave.txt data/consultas-alvo.txt
Estructura (modelo del repo de trabajo de INEMA)
docs/        diagnóstico, plano, propuesta, autorización
briefings/   <slug>.md, uno por página
data/gsc/    export semanal (solo se agrega)
reports/     semana-<data>.md, mensal-<mês>.md
scripts/     radiografía, export, informe
AGENTS.md    reglas del cliente para el agente
.env         secreto (fuera de git)
AGENTS.md · reglas del cliente
# Reglas — <cliente>
- Tono: <cómo habla el cliente>. Público: <quién>.
- Todo número o cita viene de una fuente del cliente; sin fuente, marcar PENDENTE y no publicar.
- Antes de publicar: checklist de calidad completo.
- Puerta 1: <nombre> aprueba la lista del mes. Puerta 2: <nombre> aprueba cada página.
- Nunca: publicar sin aprobación, un lote grande de una vez, una página por variación de palabra clave.
- Modelo por la suscripción. API de pago solo con autorización escrita para la finalidad.
- Secreto solo en el .env. Nunca imprimir una clave en un log o informe.

04 · Práctica: la carpeta del primer cliente

Puede ser tu propio sitio como cliente cero.

E1 · Carpeta con el secreto afuera

25 min

Crea la carpeta con la estructura, el .gitignore y el AGENTS.md completo. Haz el primer commit.

Listo cuando: el comando git status no muestra el .env, el AGENTS.md tiene tono, regla de fuente, las dos puertas con nombre y la regla de API, y el primer commit existe.

E2 · Las puertas en papel

20 min

Escribe quién aprueba cada puerta, cuánto tiempo lleva y qué pasa si la persona no tiene tiempo esa semana.

Listo cuando: la lista tiene las dos puertas con nombre, tiempo en minutos y la frase "si no hay revisión, la cadencia baja; la puerta no se salta".
