Lesson 2 · 20 min

Diagnosis: the delivered HTML, AI readiness and the questions in the AIs

The diagnosis is the first deliverable and the entry point of the sale. Three parts, all read-only: what the server delivers to the search engine, how ready the site is for AI and agents, and whether the client shows up when someone asks the AIs about their niche. It all fits on one page.

Start the lesson

In this lesson you will

  1. 1The three parts of the diagnosis and what each one answers
  2. 2Run the X-ray and the readiness score with open tools
  3. 3Build the neutral question set and freeze it
  4. 4Run the call without promising and without asking for a password

Goal: put together a site's diagnosis in three parts (delivered HTML, AI readiness, neutral questions in the AIs) and present it on a call.

01 · From first contact to a one-page report

Tap each block.

Click each block in the diagram to see what it does.

Everything is read-only. Changing the site or opening the client's dashboard requires written authorization (lesson 7).

02 · How to build each part

Tap each step.

1. X-ray

Run the method's auditoria.sh or the inemaseo-sistemas auditor on the public site, with a pause between pages.

Separate what is important (a page with no text in the HTML, wrong canonical) from what is an improvement (long title).

At INEMAOn 09/30 the course index became "search only" and 310 pages lost the only internal link the server delivered. The HTML X-ray is what catches this kind of error.

2. Readiness

The score only counts if the weights are public: the client sees why they lost points.

It measures readiness, not a guarantee of being cited. Say so in the report.

3. Question set

Build 20 questions with the client that their audience would ask, without mentioning the brand. Freeze them as v1: changing them later breaks the comparison.

Run them by hand and note the results in a spreadsheet. Answers vary: it's a sample from that day, repeated every month.

At INEMAOn 07/10/2026 INEMA showed up in 0 of 48 neutral answers on Claude and 0 of 4 on Gemini. And "What is INEMA?" brought back 4 of 4 answers about another organization with the same name: a name collision.

4. Report

Three findings with the why, the question set summary, and one next step.

The detailed teaching of the tools is in course 7 (Systems).

    05 · Practice: the first diagnostic

    Use your own site or one belonging to someone who authorized it in writing.

    E1 · X-ray and readiness

    40 min

    Run the auditor (or auditoria.sh) and agente-ready on a site of yours. Pick the 3 findings that weigh most and write, for each one, why it matters and what to do.

    Done when: you have the output files from both tools and a list of 3 findings with "why it matters" and "what to do", each with the affected URL.

    E2 · Question set v1 frozen

    45 min

    Write 20 neutral questions the site's audience would ask an AI, without the brand name. Run 5 of them by hand in 2 assistants and log them in the spreadsheet.

    Done when: the spreadsheet has the 20 questions marked as v1 and at least 10 rows filled in (5 questions × 2 assistants) with the date and "cited yes/no".
